# Image Pytorch avec Cuda 12.1

Embarque : 
- PyTorch 2.2.1 : framework de machine learning
- CUDA 12.1 : plateforme de calcul parallèle NVIDIA
- cuDNN 8 : bibliothèque de réseaux de neurones profonds

Outils de développement : compilateurs NVCC, bibliothèques mathématiques (BLAS, FFT), debugger CUDA-GDB18
